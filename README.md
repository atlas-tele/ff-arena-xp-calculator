# FF Arena XP Calculator
Separate mobile-first PWA for tracking Free Fire BR/CS ranks and XP.

## GitHub + Railway
Upload all files in this folder to your NEW repository, then create a NEW Railway service from that repository. Railway will detect Node and run `npm start`.

## Data and Firebase
This starter saves data in the current browser using localStorage. Export backups regularly. Firebase configuration is deliberately blank and cloud sync is not enabled until Firestore security rules are configured. Never put service-account private keys in frontend code.

Keep this app separate from your existing Firebase project `ffarena-4f773`.
